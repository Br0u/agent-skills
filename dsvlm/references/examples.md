# 场景案例

这些案例来自真实平台配置截图。优先用于套字段格式和组件组合，不要把阈值、预警等级当成固定业务规则。`排序` 用户未指定时默认写 `自动`。

案例类型：

- `推荐初版`：可作为新算法的默认起点。
- `历史实测案例`：保留真实平台配置，不代表当前默认推荐；套用前先按 `SKILL.md` 的简化优先、自检清单重审。
- 未标注时默认按 `历史实测案例` 处理。

## 贴广告（推荐初版）

`贴广告` 太抽象。优先识别稳定视觉模式：有人、靠近固定表面、抬手接触表面并做疑似张贴动作。不要强依赖手持纸张、胶带、新增贴纸、完成后离开等不稳定细节。

```text
算法: 识别非法张贴广告
解析模式: 通用模式
预警等级: 二级预警
启用区域框: 开
思维条件1: 目标理解 / 多模态目标理解 / person / 大于 / 0 / 阈值 50
思维条件2: 深度内容理解 / 正向深度思维1 / 画面中有人员或疑似人员靠近墙面、电线杆、门面、玻璃、设备外壳等固定表面
思维条件3: 深度内容理解 / 正向深度思维1 / 人员抬手接触固定表面，并做出按压、抹平、粘贴、固定、停留操作等疑似张贴动作
```

## 遛狗不牵绳（推荐初版）

不要强行判断“没有牵引绳”。牵引绳太细，远景低清容易漏。先触发 `人 + 狗 + 同画面`，再反向排除明确牵绳。

```text
算法: 遛狗不牵绳
解析模式: 通用模式
预警等级: 一级预警
启用区域框: 开
排序: 自动
思维条件1: 目标理解 / 多模态目标理解 / person / 大于 / 0 / 阈值 50
思维条件2: 目标理解 / 多模态目标理解 / dog / 大于 / 0 / 阈值 50
思维条件3: 深度内容理解 / 正向深度思维1 / 图中人和狗同时出现在画面中
思维条件4: 深度内容理解 / 反向深度思维1 / 图中人员手持牵引绳，且牵引绳明显连接狗或狗佩戴牵引装备
```

## 标识牌识别--正式

目标先用多模态目标理解锚定 `tag`，再用内容理解判断它是否挂在柜子上、且不是粘贴在柜子上。这里的“不是粘贴”是安装方式判断，不是默认反向排除。

```text
算法: 标识牌识别--正式

预警等级: 一级预警

思维条件1: 目标理解 / 多模态目标理解 / tag / 大于 / 0 / 阈值 30
```
